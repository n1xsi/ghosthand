**GhostHand** – это автоматизированный софт с набором скриптов для помощи в FPS-играх.

Проект является чисто _**universal** external assistaint tool_ для небольшой помощи в игре.

> [!Important]
> Repo still in development. **Everything is in its "raw" form.**

> [!WARNING]
> Данный софт – это заскриптованная имитация нажатий клавишей клавиатуры/мыши, поэтому какие-то функции могут работать дёргано, некорректно или вовсе не работать (в зависимости от игры).
> 
> Для лучшей работы программы её необходимо запускать от имени администратора, а в играх использовать режим отображения окна "Оконный" или "Полноэкранный в окне".
> 
> Все риски <b><i>Вы берёте на себя</i></b>! Программа была написана в образовательных целях! За подозрительные действия в играх вас могут **забанить**!

## ✅ Функции, реализованные на данный момент
Имеется уже готовое меню с следующими рабочими функциями:
* AimPull
* Autopistol
* Mini-Recoil Control
* Pixel Trigger Bot
* Bhop
* Anti-AFK
* Snap Tap

## 🎮 Совместимость с играми
GhostHand проверен и совместим на следующих играх (список будет пополняться):

**Полная совместимость (бо́льшая часть функций):**
* hl1
* cs 1.6 + cs:s + cs:go

**Только в Secured-режиме:**
* cs2
* Rust
* Valorant (vanguard)
